im a student, and data is my thing: not just queries, but whole data
platforms and the infrastructure underneath. ingestion, change data capture,
streaming, storage, and the kubernetes clusters it all runs on. im curious
about how systems work, how they scale, and how to build them so they solve
real problems.

im also a big open source fan. most of what i use is open source, and this
is where i document, share and build what i learn. hopefully my journey is
useful for others too ^^

### ⋆ what im into

- **data platforms**: end-to-end data infrastructure, from ingestion and change data capture to streaming and storage
- **kubernetes**: running data workloads on clusters, and the plumbing around them
- **backend**: mostly go. small clis, services, the occasional mcp server
- **cloud & security**: containers, registries, terraform on gcp, vulnerability scanning
- **open source**: building on it every day and sharing what i make

### ⋆ things i made

- [**go-cdc-lab**](https://github.com/Dem1241/go-cdc-lab) · change data capture playground with postgres, debezium and redpanda. `go`
- [**pg-mcp-live**](https://github.com/Dem1241/pg-mcp-live) · read-only mcp server for postgres: schemas, safe selects, query plans. `typescript`
- [**harbor-scanner**](https://github.com/Dem1241/harbor-scanner) · push images to harbor, trigger vulnerability scans, export the reports. `go`
- [**mariadbmanagement**](https://github.com/Dem1241/mariadbmanagement) · run and manage several mariadb instances in docker. `python`
- [**weight**](https://github.com/Dem1241/weight) · track your body weight in the terminal. watch the weekly average, not the daily noise. `go`
